**Cyber Crime Complaint Management System**  
An intelligent, web-based system designed for cyber-crime complaint registration, automatic classification, severity detection, and investigation workflow management. Developed as a part of the Bachelor of Technology (B.Tech) in Cyber Security curriculum at Central University of Jammu, Jammu and Kashmir, India.

**📌 Project Overview**  
Traditional manual complaint handling system me delays aur record management ki problems hoti hain. Yeh system un limitations ko door karne ke liye Python aur Streamlit ka use karke banaya gaya hai. Yeh automatic keyword-based analysis se cyber crimes ko classify karta hai aur relevant investigation steps generate karta hai.  
**🛠 Supported Cyber Crime Categories**  
- 💰 **Financial Fraud** (UPI, Banking scams, Phishing)  
- 📱 **Social Media Crime** (Account hacking, Identity theft)  
- 🛡 **Hacking** (Device/System compromise)  
- 📞 **CEIR Mobile Cases** (Lost/Stolen phones tracking)  
- ⚠️ **Cyber Blackmail** (Extortion, Threats)

**🚀 Key Features**  
- **Secure Officer Login:** Authentication system for authorized police officials.  
- **Keyword-Based Classification:** Automatically detects crime type from complaint text.  
- **Automated Severity & Officer Assignment:** Categorizes cases into High/Medium/Low risk and assigns specific officers.  
- **Investigation Workflow Suggestions:** Generates actionable steps based on procedures from government portals (NCRP, CEIR, etc.).  
- **Dashboard Analytics:** Visual representation of registered cases and crime trends.  
- **Report Generation:** Export options for CSV and printable reports for documentation.
